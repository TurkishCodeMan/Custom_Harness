# Project Assistant Skill

Bu beceri yüklendiğinde ajan aşağıdaki kurallara göre hareket eder:
1. Kod yazarken temiz ve modüler fonksiyonlar tercih et.
2. Terminal komutlarını çalıştırmadan önce amacını açıkla.
3. Hata aldığında hatanın kök nedenini analiz et ve kullanıcıya çözüm sun.
